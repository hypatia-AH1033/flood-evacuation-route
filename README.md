# 浸水回避避難ルート案内（仮称）

> 本リポジトリは、内水浸水情報を利用した避難経路安全性判定の実現可能性を検討するための資料・試作です。自治体公開データの形式、属性定義、二次利用条件を確認した結果、現時点では実データを用いた一般化可能な検証には至っていません。

## ⚠️ ご利用にあたって（免責事項）

- 本ツールは、**災害発生前に避難ルートを事前検討するための参考資料**です。災害発生時のリアルタイムな避難誘導を行うものではありません。
- 提示されるルート・所要時間・危険エリアの判定は、公開されているハザードマップ等のデータに基づく想定であり、**実際の浸水状況・被害を保証するものではありません**。想定を超える降雨・浸水が発生する場合があります。
- 所要時間は徒歩を前提とした参考値です。実際には道路状況や個人差により、表示より長くかかる可能性があります。
- 本ツールは、各自治体・国が公式に提供するものではありません。個人開発による非公式ツールです。
- 内水浸水想定については、対応済みの地域（[DATA_SOURCES.md](./DATA_SOURCES.md) を参照）に限られます。未対応地域は「データ無し」として表示されます。

## 概要

住所（自宅・勤務先など複数登録可）を入力すると、以下を行うツールです。

- 外水（河川氾濫）・内水（雨水出水）の浸水想定区域のうち、浸水深0.5m以上のエリアを「危険エリア」として避けた、最寄りの一時避難場所（高地）への徒歩ルートを提示（高潮浸水想定区域はルート判定には用いず、地図上の参考情報として表示）
- 危険エリアに完全に囲まれている場合は、河川沿い（外水由来の危険エリア）を除外した上で、浸水想定深度が最も浅い区域を通るルートを提示します。このとき、そのルートに含まれる浸水想定の深度範囲（例：0.5～0.8m）を表示します。通過するかどうかの最終判断は、この情報をもとにご自身で行ってください。
- 避難所候補は第3候補まで表示
- 避難所候補が土砂災害リスクと重なる場合は注釈を表示

### なぜ「0.5m」を閾値にしているか

0.5mは「歩いても安全な水深」という基準ではありません。浸水がこの水準に達すると避難行動そのものが困難になる可能性があるため、早期のルート計画段階で回避対象とするための設計上の閾値です（水は流れているため、静止した水よりも足を取られやすいことも踏まえています）。

詳細な設計方針・判断根拠は [DESIGN_DECISIONS.md](./DESIGN_DECISIONS.md) を参照してください。

## スコープ外

- 自動車での避難（浸水後の車移動はリスクが高いため対象外）
- 県をまたぐ広域対応・全国一律対応（対象は住所＋隣接市区町村まで）
- 高齢者・車椅子利用者等、要配慮者向けの個別対応
- 避難所の定員・混雑状況等のリアルタイム情報

詳細は [DESIGN_DECISIONS.md](./DESIGN_DECISIONS.md) を参照してください。

## 対応地域

外水（河川氾濫）は全国を対象としていますが、内水（雨水出水）・高潮については、各自治体のデータ利用条件を個別に確認できた地域のみ対応しています。

対応状況は [DATA_SOURCES.md](./DATA_SOURCES.md) で管理しています。「データ無し」表示の地域については、お手数ですがお住まいの自治体が公開する公式ハザードマップをご確認ください（権利関係により本ツールで扱えないことが判明している地域については、地図上に公式サイトへのリンクを併記します）。

## プライバシー

登録した住所データは、お使いの端末内（ローカル）にのみ保存されます。外部のサーバーへ送信することはありません。
